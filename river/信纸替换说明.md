# 信纸图片替换

直接替换 `assets/letters/` 中的以下八张 PNG，无须改代码：

| 城市 | 第一页 | 第二页 |
| --- | --- | --- |
| 宜昌 | yichang-1.png | yichang-2.png |
| 荆州 | jingzhou-1.png | jingzhou-2.png |
| 监利 | jianli-1.png | jianli-2.png |
| 武汉 | wuhan-1.png | wuhan-2.png |

当前每座城市两页均为不同的正式内容，可逐张替换。

## 图片制作要求

- 使用当前透明 PNG 作为模板，画布保持 **941 × 1672 像素**。
- 在模板纸张内部增加文字、插画，纸张的位置、大小、邮戳和按钮位置保持不变。
- 纸张外侧保持透明；不要加黑底或白底，也不要单独裁切信纸。
- 保存为真正的透明 PNG 文件，文件名和后缀保持上述命名。
- 左上角返回图案和右下角按钮图案可以保持原样。网页的按钮层负责点击，并在第二页覆盖为向左箭头。
- 不要删除 `next-button.png` 和 `return-button.png`，它们是两页共用的按钮素材。
- 替换后刷新浏览器；如果仍看到旧图，用 Ctrl+F5 强制刷新。线上访问可能还需要更新部署或清理平台缓存。

## 交互

点击邮箱 → 江豚到达 → 小信件弹出 → 自动居中展开第一页。
右下角：第一页进入第二页，第二页返回第一页。
左上角“返回地图”：关闭信纸，保留地图原位置。点击信纸外江面不会关闭。
阅读时地图暂停，关闭后恢复原有滚动跟随；每次重新打开从第一页开始。
